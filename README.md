# Consona downloads

Beta application downloads for Consona by Thorn & Reason. Application source is maintained separately.

## Current beta: 0.3.0-beta.2

This release fixes Linux unsaved-work confirmations and file dialogs by using the bundled GTK runtime.

- [Apple Silicon Mac installer](https://github.com/Thorn-and-Reason/Consona-releases/releases/download/v0.3.0-beta.2/Consona_0.3.0-beta.2_darwin-aarch64.dmg)
- [Windows ARM64 installer](https://github.com/Thorn-and-Reason/Consona-releases/releases/download/v0.3.0-beta.2/Consona_0.3.0-beta.2_windows-aarch64-setup.exe)
- [Windows x64 installer](https://github.com/Thorn-and-Reason/Consona-releases/releases/download/v0.3.0-beta.2/Consona_0.3.0-beta.2_windows-x86_64-setup.exe)
- [Linux x64 AppImage](https://github.com/Thorn-and-Reason/Consona-releases/releases/download/v0.3.0-beta.2/Consona_0.3.0-beta.2_linux-x86_64.AppImage)

Consona requires macOS 14 or later on Apple Silicon; Bark requires macOS 15. Intel Mac is unsupported. Windows ARM64 supports Whisper; Parakeet and Nemotron are unavailable on that target. Linux uses Whisper.

Save your work and close Consona before updating through the launcher or replacing it manually. Existing Windows x64 installations continue to receive x64 updates; install the ARM64 package manually to switch architecture. Preserve projects, recovery files, and the app-data folder.

Updater payloads have signatures bound to this release version. Mac packages remain ad-hoc signed and unnotarised; Windows packages have no Authenticode signature. Physical Fedora hardware, SELinux, audio devices, and native Windows ARM acceptance remain unverified.
